# compatible_printers_condition

> Location: Filament → Dependencies → Compatible printers

---

### Printer Condition

[Mode](../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `compatible_printers_condition`.  
[Type](../../general_settings/option_type.md#text): `Text`.  
Not available via CLI — see [Setting Overrides](../../cli/cli_mode.md#setting-overrides) for the full list of excluded keys.  
 boolean expression using the configuration values of an active printer profile.  
 If this expression evaluates to true, this profile is considered compatible with the active printer profile.
