# bed_mesh_probe_distance

> Location: Printer → Basic information → Adaptive bed mesh

---

## Probe point distance

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `bed_mesh_probe_distance`.  
[Type](../../../general_settings/option_type.md#point): `Point`.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--bed-mesh-probe-distance=100,100`.  
This option sets the preferred distance between probe points (grid size) for the X and Y directions, with the default being 50mm for both X and Y.
