> Location: Filament → Filament → Basic information

---

## Idle temperature

[Mode](../../../general_settings/option_mode.md): `Simple`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `idle_temperature`.  
[Type](../../../general_settings/option_type.md#list-types): `Integer list`.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--idle-temperature=1`.  
Nozzle temperature when the tool is currently not used in multi-tool setups. This is only used when 'Ooze prevention' is active in Print Settings. Set to 0 to disable.
