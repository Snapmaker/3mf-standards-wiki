# printable_height

> Location: Printer → Basic information → Printable space

---

## Printable height

[Mode](../../../general_settings/option_mode.md): `Simple`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `printable_height`.  
[Type](../../../general_settings/option_type.md#integer-float-percentage): `Float`.  
[Default](../../../general_settings/option_type.md#default-value): `100.0`.  
[Range](../../../general_settings/option_type.md#range): `0–214700` mm.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--printable-height=1`.  
This is the maximum printable height which is limited by the height of the build area.
