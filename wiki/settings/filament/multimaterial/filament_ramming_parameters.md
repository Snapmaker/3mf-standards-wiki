# filament_ramming_parameters

> Location: Filament → Multimaterial → Tool change parameters with single extruder MM printers → Ramming parameters

---

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `filament_ramming_parameters`.  
[Type](../../../general_settings/option_type.md#list-types): `Text list`.  
[Default](../../../general_settings/option_type.md#default-value): `120 100 6.6 6.8 7.2 7.6 7.9 8.2 8.7 9.4 9.9 10.0| 0.05 6.6 0.45 6.8 0.95 7.8 1.45 8.3 1.95 9.7 2.45 10 2.95 7.6 3.45 7.6 3.95 7.6 4.45 7.6 4.95 7.6`.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--filament-ramming-parameters=value`.  

This string is edited by the ramming dialog and contains ramming specific parameters.
