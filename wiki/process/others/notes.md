# Notes

[Mode](../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `notes`.  
[Type](../../general_settings/option_type.md#text): `Text`.  
[CLI Example](../../cli/cli_mode.md#setting-overrides): `--notes=value`.  
You can put your notes regarding this process profile here.  
They are added as a comment to the configuration block of the G-code.

```gcode
; notes = Sliced with OrcaSlicer, the best slicer.
```
