# default_jerk

> Location: Process → Speed → Jerk(XY)

---

## Default

[Mode](../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `default_jerk`.  
[Type](../../general_settings/option_type.md#list-types): `Float list`.  
[CLI Example](../../cli/cli_mode.md#setting-overrides): `--default-jerk=1`.  
Default Jerk value.

> [!NOTE]
> If this value is set to 0, the jerk will be set to the printer's default jerk.
