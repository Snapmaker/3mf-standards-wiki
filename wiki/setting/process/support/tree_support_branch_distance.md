## Branch Distance

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variables](../../../developer_reference/built_in_placeholders_variables.md): `tree_support_branch_distance`, `tree_support_branch_distance_organic`.  
[Type](../../../general_settings/option_type.md#integer-float-percentage): `Float`.  
[Defaults](../../../general_settings/option_type.md#default-value): `tree_support_branch_distance` (5), `tree_support_branch_distance_organic` (1).  
[Ranges](../../../general_settings/option_type.md#range): `tree_support_branch_distance` (`≤ 10` mm), `tree_support_branch_distance_organic` (`≤ 10` mm).  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--tree-support-branch-distance=1` (same pattern for the other variables above).  
This setting determines the distance between neighboring tree support nodes.
