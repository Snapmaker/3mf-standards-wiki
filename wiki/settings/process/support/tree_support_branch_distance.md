## Branch Distance

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `tree_support_branch_distance`.  
[Type](../../../general_settings/option_type.md#integer-float-percentage): `Float`.  
[Default](../../../general_settings/option_type.md#default-value): `5`.  
[Unit](../../../general_settings/option_type.md#unit): `mm`.  
[Range](../../../general_settings/option_type.md#range): `≤ 10`.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--tree-support-branch-distance=1`.  

This setting determines the distance between neighboring tree support nodes.
