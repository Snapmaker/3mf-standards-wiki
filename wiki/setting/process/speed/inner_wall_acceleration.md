# inner_wall_acceleration

> Location: Process → Speed → Acceleration

---

## Inner wall

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `inner_wall_acceleration`.  
[Type](../../../general_settings/option_type.md#list-types): `Float list`.  
[Default](../../../general_settings/option_type.md#default-value): `10000`.  
[Range](../../../general_settings/option_type.md#range): `≥ 0` mm/s².  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--inner-wall-acceleration=1`.  
Acceleration for [inner wall](../../process/speed/inner_wall_acceleration.md) printing. This is usually set to a higher value than outer wall printing to improve speed.
