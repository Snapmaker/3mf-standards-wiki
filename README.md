# 3mf-standards-wiki

切片软件（OrcaSlicer fork）3mf 文件格式的团队 wiki：3mf 里有什么、为什么是这样；后续扩展为 fork 的完整文档。

## 快速开始

- 新人入门：从 [wiki/home.md](wiki/home.md) 进，按 3MF 专题的顺序读
- 查证据：wiki 页面结论的原始数据在 [docs/](docs/)（盘点、字段对账、问题清单）
- 写页面：先读 [AGENTS.md](AGENTS.md)（目录、命名、链接约定）

## 仓库结构

```
wiki/    ← wiki 正文（新人向，从 home.md 进）
docs/    ← 研发内部资料：证据链与团队对齐工作文档
```
