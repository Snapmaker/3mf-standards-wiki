# compatible_prints_condition

> Location: Filament → Dependencies → Compatible process profiles

---

### Process Condition

[Mode](../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `compatible_prints_condition`.  
[Type](../../general_settings/option_type.md#text): `Text`.  
Not available via CLI — see [Setting Overrides](../../cli/cli_mode.md#setting-overrides) for the full list of excluded keys.  
A boolean expression using the configuration values of an active print profile.  
If this expression evaluates to true, this profile is considered compatible with the active print profile.
