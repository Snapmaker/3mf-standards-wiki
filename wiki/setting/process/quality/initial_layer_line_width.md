# initial_layer_line_width

> Location: Process → Quality → Line width

---

### First Layer

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `initial_layer_line_width`.  
[Type](../../../general_settings/option_type.md#integer-float-percentage): `Float or Percentage`.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--initial-layer-line-width=20%`.  
A wider first layer (with a higher [first layer height](../../process/quality/quality_settings_layer_height.md#first-layer-height)) improves bed adhesion and compensates for uneven build surfaces.  
First layer line width also overrides [Brim's](../../process/others/others_settings_brim.md) and [Skirt's](../../process/others/others_settings_skirt.md) line width.
