# fuzzy_skin_scale

> Location: Process → Others → Fuzzy Skin

---

## Skin feature size

[Mode](../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `fuzzy_skin_scale`.  
[Type](../../general_settings/option_type.md#integer-float-percentage): `Float`.  
[CLI Example](../../cli/cli_mode.md#setting-overrides): `--fuzzy-skin-scale=1`.  
Base size of coherent noise features, in mm. Larger values yield bigger, more prominent structures; smaller values give fine-grained texture.
