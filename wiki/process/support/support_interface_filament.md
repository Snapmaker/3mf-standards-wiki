# support_interface_filament

> Location: Process → Support → Support filament

---

## Interface

[Mode](../../general_settings/option_mode.md): `Simple`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `support_interface_filament`.  
[Type](../../general_settings/option_type.md#integer-float-percentage): `Integer`.  
[CLI Example](../../cli/cli_mode.md#setting-overrides): `--support-interface-filament=1`.  
Filament to print the support interface. "Default" means no specific filament for the support interface, and the current filament is used.
