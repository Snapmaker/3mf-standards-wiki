## 2. 实测继承链与各层键数

### 2.1 filament（Generic ABS 线，实测）

```text
fdm_filament_common          4 键（纯锚点，无参数）
└─ fdm_filament_abs_category  63 键（ABS 家族温度/腔温等共性）
   └─ Generic ABS @U1 base     5 键（身份键 + inherits，纯中转，instantiation:false）
      ├─ Generic ABS                114 键（0.4 默认实例，compat=U1 (0.4 nozzle)）
      └─ Generic ABS @U1 0.2 nozzle 114 键（compat=U1 (0.2 nozzle)）
```

**关键测量**：两个喷嘴兄弟实例 114 键中仅 2 键不同（`name`、`compatible_printers`）——最后一层并非"只存喷嘴差异"，而是近全量复制。

另一实测细节：`PolyLite PLA @J1`（116 键，0.4 默认）直接继承 `fdm_filament_pla_category`，而 `PolyLite PLA @J1 0.2 nozzle` 走 `@J1 base` 中转——同家族内两种挂法并存。

### 2.2 machine（两条根树，实测）

```text
fdm_klipper(53) → fdm_toolchanger(58) → fdm_U1(43) → Snapmaker U1 (0.4 nozzle)(64 键)
fdm_common(32)  → fdm_idex(42)        → Snapmaker J1 (0.4 nozzle)(12 键)
```

U1 线四层深；J1 线实例仅 12 键（绑定 + 喷嘴缩放：`printer_model`、`printer_variant`、`default_print_profile`、`nozzle_diameter`、`max/min_layer_height`）。

### 2.3 process（U1 线与 J1 线，实测）

```text
fdm_process_common(182) → fdm_process_U1 → fdm_process_U1_common(75) → fdm_process_U1_0.08(26)
                          → 0.08mm Standard @Snapmaker U1 (0.4 nozzle)(37 键)
fdm_process_common(182) → fdm_process_idex(64) → 0.16 Optimal @Snapmaker J1 (0.4 nozzle)(18 键)
```

U1 线有"机型×层高"基座（`fdm_process_U1_0.08` 等 22 个）；J1 线无机型工艺基座，实例更薄。

## 3. 三种组织风格（对"重复上移/不同下放"的回答）

| 风格 | 使用方 | 实测特征 | 取舍 |
|---|---|---|---|
| 教科书上移 | process | 182 键大头在 `fdm_process_common`，实例仅 18–37 键 | 改公共值动 1 个文件；但实例不自包含 |
| 半上移 + 实例自包含 | filament（新式，U1/J1） | 材料共性上移 category(63 键)，喷嘴兄弟各自携带 ~114 键近全量内容 | 每个实例可独立分发（配合云端 `setting_id`）；改公共值要动 N 个文件 |
| 单文件广兼容 | filament（老式，A250/A350） | `Snapmaker PLA.json`(116 键) 不分机型子预设，`compatible_printers` 列 33 个"机型 (喷嘴)" | 文件最少；无法按机型微调 |

结论：**机制上没有任何参数"必须放父"——上移纯粹是去重选择**。必须放在子（实例）层的只有：身份键（`type`/`name`/`from`/`instantiation`/`setting_id`/`inherits`）、绑定键（耗材与工艺的 `compatible_printers`；机器实例的 `printer_model`+`printer_variant`+`default_print_profile`）、喷嘴/层高缩放值。

## 4. 机制与代码依据

- 键级覆盖 + 两级回退：子键 > 父键 > `PrintConfig.cpp` 内置默认值。`fdm_filament_common` 仅 4 键却能支撑整棵耗材树，即回退到内置默认值的直接证据。
- `instantiation: false` 的基座不进 UI 选择列表。
- 用户"另存为"预设按 diff 落盘：`Preset::save(DynamicPrintConfig* parent_config)`（`src/libslic3r/Preset.cpp:621`，`config.diff(*parent_config)` 只保存与父差异的键）——运行时认可薄子件，filament 实例的全量复制是作者侧选择而非机制要求。
- 厂商清单装载：`machine_list`/`process_list`/`filament_list` 各条目带 `sub_path` 指向 JSON 文件（`PresetBundle.cpp` 云端装载入口约 L879 起）。
