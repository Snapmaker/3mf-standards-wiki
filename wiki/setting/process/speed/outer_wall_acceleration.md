# outer_wall_acceleration

> Location: Process → Speed → Acceleration

---

## Outer wall

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `outer_wall_acceleration`.  
[Type](../../../general_settings/option_type.md#list-types): `Float list`.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--outer-wall-acceleration=1`.  
Acceleration for [outer wall](../../process/speed/speed_settings_other_layers_speed.md#outer-wall) printing. This is usually set to a lower value than normal printing to ensure better quality.
