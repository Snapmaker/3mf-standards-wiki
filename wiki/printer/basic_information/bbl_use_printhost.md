# bbl_use_printhost

> Location: Printer → Basic information → Advanced

---

## Use 3rd-party print host

[Mode](../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `bbl_use_printhost`.  
[Type](../../general_settings/option_type.md#boolean): `Boolean`.  
Not available via CLI — see [Setting Overrides](../../cli/cli_mode.md#setting-overrides) for the full list of excluded keys.  
Allow controlling BambuLab's printer through 3rd party print hosts.
