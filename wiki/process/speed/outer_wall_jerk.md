# outer_wall_jerk

> Location: Process → Speed → Jerk(XY)

---

### Outer wall

[Mode](../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `outer_wall_jerk`.  
[Type](../../general_settings/option_type.md#list-types): `Float list`.  
[CLI Example](../../cli/cli_mode.md#setting-overrides): `--outer-wall-jerk=1`.  
Jerk for outer wall printing. This is usually set to a lower value than normal printing to ensure better quality.
