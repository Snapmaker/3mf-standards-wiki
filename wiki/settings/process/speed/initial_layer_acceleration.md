# initial_layer_acceleration

> Location: Process → Speed → Acceleration → Initial layer

---

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `initial_layer_acceleration`.  
[Type](../../../general_settings/option_type.md#list-types): `Float list`.  
[Default](../../../general_settings/option_type.md#default-value): `300`.  
[Unit](../../../general_settings/option_type.md#unit): `mm/s²`.  
[Range](../../../general_settings/option_type.md#range): `≥ 0`.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--initial-layer-acceleration=1`.  

Acceleration of [initial layer](../../process/speed/initial_layer_acceleration.md). Using a lower value can improve build plate adhesion.
