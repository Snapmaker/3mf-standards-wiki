# 07 对账：设置键 UI 覆盖度

> 调研基线：fork 源码 `C:\code\work_OrcaSlicer`（`src/libslic3r/PrintConfig.cpp` + `src/slic3r/GUI/Tab.cpp`，2026-11-06 版本）；wiki 侧 525 个键页面。
> 回答的问题：**UI 三个设置 Tab（Printer/Filament/Process）上的每个键，在 `wiki/setting/` 是否都有对应文档？**

## 1. 结论

**FDM 三个设置 Tab 实际挂行的参数键，wiki 覆盖率 100%，缺口为 0。** 108 个"Tab 引用但无页面"的键全部属于不适用类别（SLA 专用、双名别名、元数据/隐藏键、被注释掉的实验键、未启用特性键），详见 §3。

## 2. 口径与数字

| 层 | 数量 | 来源 |
|---|---|---|
| `PrintConfig.cpp` 定义键 | 805 | `this->add("key", …)` 去重 |
| 其中被 `Tab.cpp` 引用 | 604 | Tab.cpp 内 `"key"` 字符串 ∩ 定义键 |
| wiki 键页面 | 525 | `wiki/setting/**`（不含 3 个总览页） |
| Tab 引用键已被页面覆盖 | 496 | 页面名（含 `filament_` 前缀剥离双匹配） |
| Tab 引用键无页面 | 108 | 见 §3 分解 |
| 定义键未被 Tab 引用 | 201 | 内部/CLI/预设字段，不进设置页 |

对账时页面名与键名的匹配规则：页面名直接匹配，或剥离 `filament_` 前缀后匹配（覆盖 19 个回抽覆盖页——它们的页面名带前缀而键名不带，页面内 Variable 行写的才是真键）。

## 4. 误判修正记录

本对账经历三轮修正，记录如下（方法论教训）：

| 轮次 | 结论 | 错误原因 |
|---|---|---|
| 第一轮 | 312 键无页面 | 未过滤非 UI 键 |
| 第二轮 | 142 候选缺口 | 对所有页面名无差别剥 `filament_` 前缀，把真名即 `filament_xxx` 的页面（如 `filament_end_gcode.md`）也剥坏；Tab.cpp 匹配未过滤注释行 |
| 第三轮 | "11 个真缺口"（**错误**） | 从第二轮残留名单带出 7 个键、未对照修正后名单复核——这 7 个键（`filament_tower_*` 4 个、`filament_multitool_ramming*` 3 个）页面全部已存在；另 4 个（§3.4）为注释键 |
| 终轮 | **缺口 0** | 以"页面名 ∪ 剥前缀名"双匹配 + `append_single_option_line` 非注释行为准 |

经验：**Tab.cpp 中 `append_single_option_line("key", "page#anchor")` 的非注释行才是 UI 挂行的判据**（第二个参数即上游 wiki 页#锚点——这也解释了 2026-11-05 修复的 349 处断链的来源：批量生成时按此参数生成了上游整页路径，而本地 wiki 未建整页）。

## 5. 遗留口径备注

- 19 个 `filament_` 前缀覆盖页：文件名 ≠ 键名（键为 `retraction_length` 等无前缀名），Variable 行为准。
- `extruders_count` 页：对应 Tab 层伪键（挤出机数量 spinner），不在 `PrintConfig.cpp` 定义中，属正常。
- 覆盖度对账未纳入总览页声称的键数（104/107/311）校验，键数与 525 页一致（522 + Plate 板级键）。

## 6. 复现要点

```bash
# 定义键
grep -oE 'this->add\("[a-zA-Z0-9_]+"' src/libslic3r/PrintConfig.cpp | sed 's/.*("//;s/"//' | sort -u
# UI 挂行键（Tab.cpp 非注释 append 行）
grep -oE 'append_single_option_line\("[a-zA-Z0-9_]+"' src/slic3r/GUI/Tab.cpp | sed 's/.*("//;s/"//' | sort -u
# 页面名
find wiki/setting -name '*.md' ! -name '*_overview.md' -printf '%f\n' | sed 's/\.md$//'
# 对账 = UI挂行键 − (页面名 ∪ 剥filament_前缀页面名)
```
