# initial_layer_acceleration

> Location: Process → Speed → Acceleration

## Initial layer

[Mode](../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../developer_reference/built_in_placeholders_variables.md): `initial_layer_acceleration`.  
[Type](../../general_settings/option_type.md#list-types): `Float list`.  
[CLI Example](../../cli/cli_mode.md#setting-overrides): `--initial-layer-acceleration=1`.  
Acceleration of [initial layer](../../process/speed/speed_settings_initial_layer_speed.md). Using a lower value can improve build plate adhesion.
