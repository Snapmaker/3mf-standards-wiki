# filament_start_gcode

> Location: Filament → Advanced → Filament start G-code → Start G-code

---

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `filament_start_gcode`.  
[Type](../../../general_settings/option_type.md#list-types): `Text list`.  
[Default](../../../general_settings/option_type.md#default-value): ` `.  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--filament-start-gcode=value`.  

These settings allow you to define custom G-code commands that will be executed at the start of a print using a specific material. This can be useful for priming the nozzle, purging old filament, or performing any other necessary actions before printing.
