# travel_acceleration

> Location: Process → Speed → Acceleration

---

## Travel

[Mode](../../../general_settings/option_mode.md): `Advanced`.  
[Variable](../../../developer_reference/built_in_placeholders_variables.md): `travel_acceleration`.  
[Type](../../../general_settings/option_type.md#list-types): `Float list`.  
[Default](../../../general_settings/option_type.md#default-value): `10000`.  
[Range](../../../general_settings/option_type.md#range): `≥ 0` mm/s².  
[CLI Example](../../../cli/cli_mode.md#setting-overrides): `--travel-acceleration=1`.  
Acceleration of [travel](../../process/speed/travel_speed.md) moves. This is usually set to a higher value than normal printing to reduce travel time.
